## Gotchas (will bite you)

- **`CLAUDE.md` and `AGENTS.md` must be byte-identical** — enforced by `.githooks/pre-commit`. Do not
  reintroduce a one-line `@AGENTS.md` import; edit both identically or the commit fails.
- **PDF regeneration** has no script — print the HTML via headless Chrome:
  `chrome --headless --disable-gpu --no-pdf-header-footer --print-to-pdf="OUT.pdf" "file:///ABS/IN.html"`
  (the deck is landscape via `@page`; the brief is portrait). Regenerate PDFs whenever you change HTML.
- **Model edits go in `render_camp_models_v2.py`** (the `MODELS` dict of color-sequence strings +
  scrim sets), then re-run to regenerate HTML, then re-print PDFs, then sync the markdown tables and
  grill-state. The `check_acclimatization()` + `check_no_stacked_red()` gates will reject illegal
  sequences at render time — trust them.
