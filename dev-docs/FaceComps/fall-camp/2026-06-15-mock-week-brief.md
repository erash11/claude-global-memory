# 2026 Mock Game Week — Briefing Note

**Date:** 2026-06-15  **For:** Dave Aranda + defensive staff
**Companion to:** the six candidate camp models (`2026-fall-camp-models-v2`). This note covers the
piece those models deliberately *do not* vary: the runway from the end of install camp into Auburn.

---

## 1. Where it sits — the convergence point

Every one of the six camp models ends in the **same** runway. It is shown once on the deck because
it does not change with the model you pick:

> install camp (Aug 5–22) → **mock week, run as a game week (Aug 23–28)** → **Mock Game, Sat Aug 29**
> → game week (Aug 31–Sep 4) → **Game 1 vs Auburn, Sat Sep 5**

This is the **goal the whole ramp points at.** The install camp is how we build them up; the mock
week is the destination. By the time they run the mock, it is the *second* time they have done a
game-week load — Auburn week is the third, not the first.

## 2. What it is — LOCKED decision (2026-06-15)

**The Mock Game is a controlled rehearsal of operations and timing — not a collision day.** It runs
the in-season game-week *cadence* at game-week *operations*, not game-week *contact*. (Staff-wide,
upgrading the prior "AJ & Coach Red: mock game = green day" note.)

Why it matters: a live/competitive mock would re-spike load during the taper's bleed-off and break
the freshness math every camp model is built to protect. **If the room pushes to make the mock
competitive, that is the line to hold.**

## 3. The cadence it rehearses — FINALIZED (2026-06-15, Aranda staff; refined 2026-06-16, AJ)

The mock week is run **identical to an in-season Auburn game week** — same day-qualities, same
operations, same Mon→Sat rhythm. The only differences: there is no opponent, and the Saturday mock
is controlled contact (§2). It is **not** softened beyond that — a normal game week (100%) is
already a step down from the Block-4 camp peak (120%), so running the real game week *is* the taper.

| Day | Date | Quality | Dress | Emphasis | ~Target |
|-----|------|---------|-------|----------|---------|
| Sat | Aug 22 | **Film / off** — camp ends (Block 4 peak was Aug 18–21) | — | — | — |
| Sun | Aug 23 | **Green** — spin back up off the film/off day | Helmets · Tag | Activation / install | ~69 min |
| Mon | Aug 24 | **Green** — ramp into the week | Helmets · Tag | Install · **coming out** + base | ~69 min |
| Tue | Aug 25 | **Red — the grind** (week's hardest, game-week magnitude) | **Full Pads · Thud** | **Red zone / short yardage** (condensed field, collision work) | ~105 min |
| Wed | Aug 26 | **Yellow** — volume day | Shells · Thud | **3rd down** — tempo, vertical plays downfield | ~88 min |
| Thu | Aug 27 | **Walk-through** — **MD-2** | — | Game-plan walk | light |
| Fri | Aug 28 | **Fast Friday (green)** — speed / sharpen | Helmets · Tag | MD-1 — situational tempo | ~60 min |
| Sat | Aug 29 | **MOCK GAME** — game-day operations, controlled contact | Game ops | MD-0 — full game operations | ~92 min ops |

**Tue→Sat mirrors Auburn week exactly** (Tue grind → Wed yellow → Thu walk-through → Fri fast →
Sat game); Sun–Mon is the on-ramp off the Aug 22 film day. The week **self-tapers** into the mock,
and the mock being controlled keeps Saturday below a true game load. Colors here are game-week
day-*qualities* (the week's rhythm), not camp duration-bands — even the Tuesday "red" sits at
in-season magnitude, far below a camp red. (Supersedes the prior generic P1–P5 MorphoCycle table.)

**Emphasis logic (AJ refinement, 2026-06-16):** the physical and volume stimuli are split across the
two work days rather than stacked. **Tuesday is the collision day** — full pads, condensed field
(red zone / short yardage) for blocking and tackling in tight space; that mirrors how the regular
season runs its hardest day. **Wednesday is the volume day** — a red-zone emphasis there would *not*
deliver the volume stimulus the yellow day is for (condensed spaces cap reps), so it gets the 3rd-down
work with tempo and vertically-oriented plays downfield. **Coming out** installs early in the week
(Mon), the way we use it in-season. Counting back from the Saturday mock (MD-0): Friday fast Friday
is MD-1, so the **Thursday walk-through is MD-2** (corrected from the prior "minus 1" label — the
mock is on Saturday, not Friday).

## 4. Decisions taken in the 06-15 meeting (formerly open)

1. **Framing — game week, not just a taper.** Run it as a real game week (the table above), not a
   loosely-tapered camp block. The rehearsal value is in matching the rhythm they'll live 12 weeks.
2. **Cadence depth — full week, day-of-week aligned.** Keep Tuesday as the grind and Friday as fast
   Friday so the mock week and Auburn week share the exact Mon→Sat shape (closes branch **B6**).
3. **The mock = the "game day"** of the rehearsal week (Sat Aug 29), mirroring the Sat Auburn game.
4. **Front of the week:** Aug 22 (Sat) = film/off; Sunday carries the green; **Monday = green** (a
   smooth ramp into the Tuesday grind rather than a Monday off).
