# 2026 Fall Camp — Candidate Macro Models

**Date:** 2026-06-05  **For:** Dave Aranda + defensive staff (pick one to react to)

Three calibrated builds of the 14 install days (P1–P14, Aug 5–21), all on the authoritative page-1 camp skeleton (`SourceFaces/Camp_Models.pdf`). Day-type targets (GPS-realized): **GREEN 85 min / 9 per · YELLOW 112 / 12 · RED 132 / 13–14**, anchored to a 92-min game day. Situational themes are unchanged from the staff draft; **dress/tempo and recovery were re-sequenced** to fix the front-loaded pattern (every change flagged). Color is the internal layer — the coach-facing render drops the traffic-light coding (Aranda's call). See design spec `docs/superpowers/specs/2026-06-04-fall-camp-2026-load-model-design.md`.

## The problem being fixed (as-drafted page-1 plan)

As-drafted = 4G / 4Y / 6R but **front-loaded**: Block 2 already runs two red days and Blocks 2–4 each carry two reds, so the back block is no harder than the middle. That repeats Baylor's 2024/25 accumulated-fatigue pattern. All three models below instead ramp the **block average-day intensity** up to a single clean Block-4 peak.

## Side-by-side

| Model | G/Y/R | Block avg-day ramp (% game day) | Camp peak day | Character |
|---|---|---|---|---|
| Conservative | 5/6/3 | 102 -> 112 -> 120 -> **125** | 143% (Block 4) | Most recovery; a green after every red. Lowest total load. Safest into Game 1. |
| Moderate | 5/4/5 | 102 -> 119 -> 120 -> **131** | 143% (Block 4) | Textbook polarized build. Recovery between hard days except the peak block. The working recommendation. |
| Aggressive | 2/5/7 | 112 -> 129 -> 131 -> **138** | 143% (Block 4) | Runs hot, minimal recovery, closest to Baylor's historical loads. Contrast / max-stress option. |
