# Performance Playbook — transferred project context

Carried over from the Claude cloud project, Sept 2026.

## Objective

Comprehensive educational resources for intern training programs. Standardized reusable
templates that support sports science technology education and ensure consistent delivery
of curriculum content.

The technologies integrated into the learning framework: force plates, GPS monitoring,
velocity-based training, heart rate analysis, tensiomyography.

Curriculum development draws on established programs like Clemson's, while holding
Baylor's institutional standards and branding.

Success means materials that adapt efficiently across different technologies and deliver
consistently to interns over multiple program cycles.

## Current template state

**Word SOP template.** Proven two-column format with visual hierarchy: dark headers,
color-coded text (red for warnings, blue for notes). Systematically covers the technology
lifecycle from setup through data management.

**PowerPoint template.** Baylor official colors, green `#154734` and gold `#FFB81C`, with
approved typography. Structured as a 16-week curriculum framework covering both technical
skills and soft skills development.

## Formatting standards

Two-column layouts, consistent visual hierarchy, and placeholder systems for efficient
customization. Baylor University's official brand standards govern all visual and
typographic elements, for institutional consistency across educational materials.

Microsoft Word and PowerPoint are the primary platforms.
