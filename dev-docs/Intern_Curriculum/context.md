# Intern Curriculum — transferred project context

Carried over Sept 2026.

## What it is

A module-based internship curriculum for sport science, designed independent of Baylor's
academic structure. Active project.

Designing it outside the academic structure is the deliberate choice: it means modules
can be sequenced by what an intern needs to be useful in the department, rather than by
what fits a semester.

## Repo state

Currently holds one artifact: `FA2026_ClemsonInternCurriculum_Sample.zip`, a 45 MB
reference sample from Clemson's program used for structural guidance.

That is the whole of what was on the primary storage drive at repo creation. The Baylor
curriculum itself is either unbuilt or lives elsewhere. Worth resolving.

## Recommended first step

Unpack the zip into real files. At 45 MB it sits above GitHub's 50 MB warning line, and
every revision stores a full new copy. Unpacked, the contents become diffable and the
repo stops doubling on each change.
