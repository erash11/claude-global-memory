**Goal:** Add a "Coach Target" tab to the HTML tool so dietitians can enter a coach-assigned target weight and see projected time to reach it at each gain pace.

**Architecture:** Single-file change to `scripts/02_generate_tool.py`. The HTML tool gains two top-level tabs ("Elite Benchmarks" and "Coach Target") implemented in vanilla JS. The Python generation logic is unchanged — only the HTML/CSS/JS template strings inside `build_html()` are modified.

**Tech Stack:** Python 3.8+, vanilla JS, inline CSS — no new dependencies.

## Design Reference

### Tab Bar

Two tabs below the input card:
```
[ Elite Benchmarks ]  [ Coach Target ]
```
- Active tab: `#154734` green background, `#FFB81C` gold text, 3px gold bottom border
- Inactive tab: white background, `#555` text, 1px `#dde1e7` border
- Tab bar is sticky (`position: sticky; top: 0; z-index: 100`)

### Tab 1 — Elite Benchmarks (existing content, unchanged)
Exactly the current results section. No logic changes.

### Tab 2 — Coach Target

**Additional input** (shown only when Coach Target tab is active, rendered inside the tab panel itself):

```
Coach Target Weight (lbs): [ number input, min=100, max=500 ]   [ Calculate ]
```

**Results** (shown after Calculate is clicked):

**If target ≤ current weight:**
```
Green summary card: "This player at [X] lbs already meets or exceeds the coach target of [Y] lbs."
```

**If target > current weight:**
```
Green summary card: "To reach the coach target of [Y] lbs, this player needs to gain [gap] lbs."

Simple result card:
  Realistic:    X.X months   (or "12+ months")
  Aggressive:   X.X months
  Exceptional:  X.X months
```

Three values displayed as a clean 3-column stat row (not a full table — simpler format per user preference).

### Coach Target calculation

Uses the same `timeToTarget(gap, pos, pace)` function already in the tool:
```javascript
function analyzeCoachTarget() {
  // 1. Validate position and current weight (same checks as analyze())
  // 2. Get coach target weight (validate: number, 100-500 lbs range)
  // 3. Compute gap = targetWeight - currentWeight
  // 4. If gap <= 0: show "already meets" card, hide result stats
  // 5. If gap > 0: compute timeToTarget(gap, pos, "realistic"/aggressive/exceptional)
  // 6. Show results
}
```

```javascript
// ── Coach Target ─────────────────────────────────────────────────────────────
function analyzeCoachTarget() {{
  const posEl       = document.getElementById("pos-select");
  const weightEl    = document.getElementById("weight-input");
  const targetEl    = document.getElementById("coach-target-input");
  const errEl       = document.getElementById("coach-error-msg");
  const resultsEl   = document.getElementById("coach-results");
  const statCardEl  = document.getElementById("coach-stat-card");

  const pos         = posEl.value;
  const weight      = parseFloat(weightEl.value);
  const targetWeight = parseFloat(targetEl.value);
  const posLabel    = POSITION_LABELS[pos];

  // Validate
  errEl.style.display = "none";
  if (!pos) {{
    errEl.textContent = "Please select a position in the Player Information section above.";
    errEl.style.display = "block"; return;
  }}
  if (isNaN(weight) || weight < 100 || weight > 400) {{
    errEl.textContent = "Please enter a valid current weight (100–400 lbs) in the Player Information section above.";
    errEl.style.display = "block"; return;
  }}
  if (isNaN(targetWeight) || targetWeight < 100 || targetWeight > 500) {{
    errEl.textContent = "Please enter a valid target weight between 100 and 500 lbs.";
    errEl.style.display = "block"; return;
  }}

  const gap = targetWeight - weight;

  if (gap <= 0) {{
    // Player already meets or exceeds target
    document.getElementById("coach-summary-text").innerHTML =
      `This player at <span class="highlight">${{weight}} lbs</span> already meets or exceeds ` +
      `the coach target of <span class="highlight">${{targetWeight}} lbs</span>.`;
    statCardEl.style.display = "none";
  }} else {{
    // Show projection
    document.getElementById("coach-summary-text").innerHTML =
      `To reach the coach target of <span class="highlight">${{targetWeight}} lbs</span>, ` +
      `this player needs to gain <span class="highlight">${{gap.toFixed(1)}} lbs</span>.`;
    document.getElementById("coach-realistic").textContent   = timeToTarget(gap, pos, "realistic");
    document.getElementById("coach-aggressive").textContent  = timeToTarget(gap, pos, "aggressive");
    document.getElementById("coach-exceptional").textContent = timeToTarget(gap, pos, "exceptional");
    statCardEl.style.display = "block";
  }}

  resultsEl.style.display = "block";
  resultsEl.scrollIntoView({{ behavior: "smooth", block: "start" }});
}}

// Allow Enter on coach target input to trigger calculation
document.addEventListener("DOMContentLoaded", function() {{
  const coachInput = document.getElementById("coach-target-input");
  if (coachInput) {{
    coachInput.addEventListener("keydown", function(e) {{
      if (e.key === "Enter") analyzeCoachTarget();
    }});
  }}
}});
```

**Important:** The existing `DOMContentLoaded` listener for `weight-input` Enter key is already in the template. Add this as a second `DOMContentLoaded` block — both will fire. Do not replace the existing one.
