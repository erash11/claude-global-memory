# Separate research access from knowledge promotion

**Status:** Superseded in part by [ADR 0008](./0008-use-automatic-zotero-first-research-grounding.md)

All Source Papers in Zotero are available for on-demand retrieval. The original decision limited durable promotion
to explicitly selected papers; ADR 0008 retains the separation and validation boundary while replacing the manual
selection boundary with an explicit full-library backlog and promotion scope.
