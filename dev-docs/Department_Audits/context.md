# Department Audits — transferred project context

Carried over from the Claude cloud project, Sept 2026.

## The framing that matters

The goal is executable audit frameworks for athletic departments, not purely
informational documentation. If a deliverable explains auditing rather than enabling
someone to run one, it has missed.

Stakeholders for the outputs: Athletic Directors, Head Coaches, and support staff.

The work synthesizes existing audit methodologies, interview protocols, and assessment
frameworks into actionable playbooks that guide systematic departmental evaluations.

## Current state

A substantial collection of audit resources has been assembled: frameworks, interview
guides, checklists, and templates specific to sport performance auditing. Those have
been synthesized into a comprehensive operational playbook that works as an executable
plan.

The documentation has been refined using structured communication principles to make it
persuasive and action-oriented, leading with clear answers rather than procedural
descriptions.

## Approach and patterns

- **Synthesis first.** Gather comprehensive source materials before creating unified
  executable deliverables.
- Apply structured communication frameworks, particularly the Pyramid Principle, when
  refining documentation, so procedural content becomes persuasive stakeholder-appropriate
  guidance.
- Working pattern: systematic document retrieval, then content integration, then
  strategic revision, so final outputs are action-oriented.

## Where the materials live

Audit materials are kept in Google Drive under clear naming conventions that make
retrieval easy. The collection includes the Sport Science Audit Framework plus supporting
interview guides and assessment checklists.

Google Drive integration enables efficient synthesis, but larger framework documents
occasionally present access challenges that need workaround strategies.

Only a small set of files was present on the primary storage drive when this repo was
created. The bulk is still in Google Drive.
