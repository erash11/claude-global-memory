## Standing meeting — proposed structure

Weekly, 30 minutes, Eric + Micah, with others pulled in as needed.

1. **Open requests** — status, and specifically what is blocked and on whom
2. **New requests since last week** — did each arrive with a completed review record
3. **Anything that arrived off-process** — how it got in, so the routing gets fixed
4. **One process item** — a single improvement per week rather than a standing debate

Then Eric reports out to Cody Hall, Jovon Overshown, and Kenny after each meeting, per
Kenny's instruction.
