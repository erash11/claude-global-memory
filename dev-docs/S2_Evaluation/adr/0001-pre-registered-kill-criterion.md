# Pre-register a kill criterion before examining the data

This project is self-initiated exploratory analysis with no external requester,
which is the exact condition under which analysts unconsciously move goalposts
until something looks interesting. We therefore commit, in writing and before
any data is examined, to a threshold below which the premise is declared false
and the project stops.

The premise under test: that composite percentiles hide actionable Profile
Unevenness. If athletes' category scores turn out to be largely flat, the
composite hides nothing and there is no project.

**Threshold: pending CSV schema.** The specific number cannot be set responsibly
until the category count and scale are known. The commitment recorded here is to
fix that number *before* looking at any athlete's results — not to any
particular value.

## Consequences

Once set, the threshold may not be lowered after seeing results. If it is
missed, the honest outcome is a short written negative finding, which has real
internal value and is a legitimate end state for this work.
