# V1 is a shape-only retrospective for one room, reviewed internally

Four scope cuts, taken together, because each one individually invites reversal
under pressure.

1. **One-off retrospective**, not a recurring per-cycle product. A pipeline
   built before anyone has changed a decision is the "data collection without a
   clear plan" failure already logged in the 2026-06-08 EOY Kitman meeting.
2. **A single room**, though the eventual ambition is every position group.
3. **Sports science internal is the only audience.** Position coaches and S&C
   are tier 2 and not yet engaged; athletes are out of scope entirely.
4. **Shape only — v1 does not prescribe.** Under a Position Fit frame,
   prescribing means telling a coach to move a player, which is a
   talent-identification claim this project is not equipped to defend.

## Consequences

Cut 4 means v1 delivers only the first half of the Beyond Percentiles
definition. This is a deliberate scope cut and explicitly *not* a redefinition
of the term — the prescription half remains the standing goal, deferred rather
than abandoned.
