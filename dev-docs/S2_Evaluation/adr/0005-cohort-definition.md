# Include every lineman with data; use the most recent test

**Inclusion.** Every offensive lineman with S2 data is in the room, regardless of
scholarship status, class year, or whether he is a realistic contributor.
Roster status and class are recorded as attributes but are never used to filter.

Filtering to "guys who actually play" would define the typical lineman as
whoever the staff already selected, and the analysis would then discover that
the selected players are typical. That is the same selection circularity the
Position Fit framing was resolved to avoid. Keeping everyone also preserves a
genuine question — whether Room Deviation tracks roster status at all — that a
filter would have silently destroyed.

**Observation.** Where an athlete has tested more than once, the most recent
result is used. Current state is what a coach acts on, and fixing the rule
before the data is examined prevents selecting whichever date tells a cleaner
story.

## Consequences

Change-over-time is excluded from v1. It is a real question, but it belongs to
the *static* complaint deprioritized in the Beyond Percentiles definition, and
folding it in would roughly double v1's scope.
