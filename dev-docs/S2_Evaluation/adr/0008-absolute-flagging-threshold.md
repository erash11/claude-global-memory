# Flag at 1.5 SD from the room mean, not top-N

An athlete is flagged when he sits at least 1.5 population standard deviations
from the room mean on any single category. Fixed before the data is examined,
for the same reason as the kill criterion in ADR 0001.

## Considered and rejected: ranking and taking the top three

A top-N rule always returns exactly N names, whether or not the room contains
anyone genuinely unusual. It would let a homogeneous room produce a confident
list of "deviant" linemen who are merely the least average — manufacturing a
finding from noise.

## Consequences

An absolute threshold can return zero flagged athletes. That is a real result
and reports as one: it says the room is cognitively homogeneous, which is itself
worth knowing.
