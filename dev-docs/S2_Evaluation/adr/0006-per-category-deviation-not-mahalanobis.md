# Per-category deviation in population-SD units, not Mahalanobis distance

Room Deviation is computed per category, as the athlete's distance from the room
mean expressed in population standard deviations. The headline ranking statistic
is each athlete's maximum absolute deviation across categories.

This yields both a sortable single number and an immediate answer to "deviant in
*which* way" — which is the entire reason for going beyond a composite. A single
centroid distance would have reintroduced the exact collapse the project exists
to undo.

## Considered and rejected: Mahalanobis distance

Mahalanobis is the textbook answer for multivariate deviation and someone will
propose it again, so the rejection is recorded here. With roughly fifteen
linemen and several categories, the covariance matrix is too poorly estimated to
be trusted. It would manufacture false precision and produce a number no
position coach could be walked through.
