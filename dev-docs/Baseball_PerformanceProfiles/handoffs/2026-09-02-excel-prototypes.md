# Handoff — Baseball Performance Profiles, Excel prototypes

**Date:** 2026-09-02
**Status:** Prototypes built. Waiting on the coach.

## What this is and why

Baylor baseball's strength & conditioning coach wants athlete performance
profile reports. He is an old-school coach who works strictly in MS Excel.
He is not impressed by web interfaces. So the deliverable is **.xlsx files he
opens and prints** — not a dashboard, not an HTML report, no server, no login.

This is the baseball counterpart to `~/DEV/PlayerProfiles_FB_03-28-2026`
(football), which delivers a static HTML report. Same scoring idea, different
medium.

## Approach taken

Invoked `mattpocock-skills:prototype`. That skill has two branches: "does the
logic feel right" and "what should this look like". This is the second one.
The skill's stock mechanics for that branch are web machinery (one route, a
URL search param, a floating variant switcher) — wrong artifact for this
audience. Adapted it: **"several radically different variations" became three
separate workbook files**, since the coach's medium is Excel itself.

The prototype answers exactly one question: **which report SHAPE does he
want?** Not which metrics, not how the pipeline works. So no real data is
wired — mock data only, and every sheet is stamped MOCK DATA in red.

## Decisions worth keeping

- **xlsxwriter, not openpyxl.** openpyxl cannot write sparklines. The
  per-metric trend lines in variants A and B need them.
- **Formulas carry cached values.** `write_formula` was given the computed
  result for the default-selected athlete in variant B, so previewers that
  do not recalculate still show numbers instead of blanks.
- **Variant B uses data validation + INDEX/MATCH, not a macro.** Macros mean
  .xlsm, security warnings, and an IT conversation. Not worth it for a
  dropdown.
- **T-score scoring, copied from the football system.** Team mean = 50, every
  10 points = 1 SD. The 10-yard sprint is inverted because lower is better.
  Composite = unweighted mean of the four domain scores.
- **Body weight is display-only**, not scored — same call the football system
  makes.
- **Registered in the `job` lane**, rank 15, stage `building`. The `/project`
  skill says to ask which lane; the call was made without asking because the
  work is for a Baylor coach. Easy to flip in `portfolio.json`.
