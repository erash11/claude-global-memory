# Portfolio — transferred project context

Carried over from the Claude cloud project, Sept 2026.

## The Indiana opportunity

Materials were built for a professional interview at Indiana University, needing pieces
that communicate the approach to athletic performance and sport science integration.

A comprehensive trifold brochure was completed as the leave-behind piece. It showcases:

- The Three Pillars of Service (R&D, Education, Analytics)
- The Sport Science Integration Model with bidirectional data flow
- The Technology Ecosystem with the Tiered Service Model

## Branded variants

Multiple versions exist, optimized for the interview process:

- Original Baylor styling
- Full Indiana University branding
- Subtle IU accent version

Branding elements (color schemes, institutional identity) get adapted per organizational
context. That adaptation pattern is reusable for any future opportunity.

## Production approach

Source materials were portfolio presentations and professional headshots. Deliverables
are multi-format, including trifold brochures optimized for professional printing.

## Files on hand

`materials/` holds resumes, portfolio decks, cover letters, and leave-behinds.
`materials/INDIANA/` holds the IU-specific set: cover letter, letter of interest,
portfolio variants, and two leave-behind PDFs (Full and Subtle). A `PRINT` subfolder
holds print-ready versions.

Several portfolio deck variants exist (Portfolio_1, Portfolio_2, PrintV2, PrintV2_ALT).
